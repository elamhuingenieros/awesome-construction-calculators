# Contributing

Pull requests are welcome. An entry is added when it:

- is a calculator or a reference a person in the building trades uses at work;
- can be used for free, in the browser, without creating an account (say so if part of it is paid);
- says plainly what it calculates, and preferably which standard or formula it follows.

Write the entry as one line: `- [Name](link) — what it does.` Put it under the right heading, keep the list's order, and do not use words such as "best" or "ultimate": describe the tool and let the reader decide.

Links that stop working are removed.
